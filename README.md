# Sistem Informasi Posyandu Ramah Lansia Lawang

Selamat datang di repositori Sistem Informasi Posyandu Ramah Lansia Lawang. Sistem ini dibangun untuk mempermudah pencatatan, pemantauan, dan pengelolaan data lansia serta jadwal kegiatan Posyandu di Kecamatan Lawang.

🌐 **Website Resmi:** [posyanduramahlansialawang.id](https://posyanduramahlansialawang.id)

## Fitur Utama

- **Pendataan Lansia:** Mengelola informasi pribadi dan riwayat kesehatan lansia.
- **Jadwal Posyandu:** Informasi lengkap mengenai jadwal pemeriksaan dan kegiatan Posyandu.
- **Pemeriksaan Kesehatan:** Pencatatan hasil pemeriksaan rutin lansia.
- **Berita & Edukasi:** Artikel edukatif dan berita seputar kegiatan Posyandu Lansia.
- **Galeri:** Dokumentasi kegiatan kader dan lansia.

## Teknologi yang Digunakan

Proyek ini dibangun menggunakan teknologi modern:
- **Frontend:** React, TypeScript, Vite
- **Backend:** Node.js, Express, Drizzle ORM
- **Database:** MySQL

## Cara Menjalankan Secara Lokal

Jika Anda ingin menjalankan proyek ini secara lokal untuk pengembangan, ikuti langkah-langkah berikut:

### Persiapan
Pastikan Anda sudah menginstal Node.js dan npm di komputer Anda.

### Menjalankan Frontend
1. Buka terminal dan arahkan ke folder root proyek.
2. Instal dependensi:
   ```bash
   npm install
   ```
3. Jalankan server pengembangan:
   ```bash
   npm run dev
   ```

### Menjalankan Backend (Server)
1. Buka terminal baru dan masuk ke folder `server`:
   ```bash
   cd server
   ```
2. Instal dependensi backend:
   ```bash
   npm install
   ```
3. Sesuaikan konfigurasi `.env` dari file `.env.example`.
4. Jalankan server backend:
   ```bash
   npm run dev
   ```
